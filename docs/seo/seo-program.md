# SEO program — goals, batches, monitoring

Working docs for the search-intent content program on qr.w-app.online.
Spec: docs/superpowers/specs/2026-10-19-seo-program-design.md

## Strategy

Long-tail guide pages first (one search intent per page), head terms last.
Every page: unique substance over a shared template — doorway pages get
penalized, distinct value ranks. English only.

## Batch 1 (2026-10-19)

link, wifi, vcard, event, sms, instagram, facebook — each slug carries the
exact query form.

## Batching rule

Never grow the backlog from guesses. A new batch goes in when Search Console
shows for a query family: impressions arriving, CTR weak (page-2 position),
and a builder type that can serve the intent. Then write that batch.

## Monthly loop (first week of the month)

1. Search Console → Performance: record impressions, clicks, avg position in
   the table below
2. Search Console → Pages: indexed/queued/errors
3. New batch decision per the rule above
4. Backlink checklist: docs/seo/backlinks.md — one action

## Success criteria (honest)

- App + guides indexed: inside ~2 weeks of deploy
- Impressions on guide queries: 1–2 months
- Handful of long-tail queries top-10: ~6 months
- Head terms ("qr code generator"): years-long race, tracked, not promised
