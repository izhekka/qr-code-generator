# Backlink playbook — human work, never automated

Goal: relevant links into https://qr.w-app.online from places that already
discuss QR codes or free tools. One link from a real page beats fifty from a
directory that exists for links. Never buy links, never post where a tool is
unwelcome — visible manipulation gets sites penalized in practice.

## Week of launch

- [ ] Repo README (izhekka/qr-code-generator): add the live site link at the top
- [ ] Product Hunt: "Coming soon" page, launch when the guides batch is live
- [ ] Hacker News: "Show HN" post with a builder screenshot, be in the comments
- [ ] Reddit r/coolgithubprojects + r/InternetIsBeautiful: one honest post each

## First month

- [ ] Curated tool aggregators: submit to the free-tool directories that list
      generators like this (free-for-dev lists, alternative.to-style entries)
- [ ] Hospitality/catering communities: guest Wi-Fi QR is a standing pain point
      — answer the question first, link only where it solves it
- [ ] Event-planning communities: menu QR, schedule QR posts

## Ongoing

- [ ] After each guide batch: pick the 1–3 communities where that exact topic
      (SMS ordering, vCards at expos…) is discussed and contribute
- [ ] Track discovered links in Search Console → Links; ignore the volume,
      watch the relevance
